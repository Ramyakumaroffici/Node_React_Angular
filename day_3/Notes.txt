MongoDB -

it is developed by MongoDB inc in 2009

it is written in C, C++, javascript.

MongoDB is an open source NoSQL database which provides high performance
and it is felxible as well.

it is also called as NoSQL database because 
it doesn't depends on RDBMS(Relational database management system)


** we can store unstructured data in mongodb that's why
it is called as schema less data model.

MongoDB comes under the category of document oriented database.

comparison query operator?

$eq - it matches the value which is equal to the specifying value.

$gt - it matches the value which is greater to the specifying value.

$gte-it matches the value which is greater than equal to the specifying value 

db.users.find({age:{$eq:22}});

db.users.find({age:{$gt:22}});

db.users.find({age:{$gte:22}});

$lt and $lte

$in - it matches the value that is available in the array.

db.users.find({city:{$in:["Gurugram","delhi","kolkata"]}})

$nin -it matches the value that is not available in the array.

 db.products.find({city:{$nin:["chennai","mumbai","pune"]}})
